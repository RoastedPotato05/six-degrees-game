How To Play

After choosing a starting item and a target item, the goal is simply to navigate from the starting item to the target item using the on-screen buttons for cast/crew and movies/tv. By default, you're given lots of information about people's credited works, movie cast and crew lists, as well as cast and crew for television shows. You're also given info cards that display some information about the target item(s), such as the starring actors and directors.

Customization is also available in the Settings menu, such as limiting options to only television or movies and banning specific items, which prevents them from appearing in your runs.


STANDARD

This is the standard gamemode, choose one starting item and one target item. You can use the small dice buttons at each input box to roll for a random item for that input, or use the large dice button to quickly start a run with a random start and target item.


DETOUR

In this gamemode, you choose one starting item, one target item, and any number of detour items. These detours can be visited in any order, but all of them must be visited before the target item.


ENDLESS

In Endless mode, you choose a starting item and a target item, then after reaching the target item a new target is randomly chosen. In this mode. the player is NOT allowed to revisit items from previous target paths, but you can still revisit items in the current target's path.
